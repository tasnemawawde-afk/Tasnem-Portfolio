# WCAG 2.2 AA — the ten that matter for a personal site
| # | Criterion | Quick test |
|---|---|---|
| 1.1.1 | Non-text content | Every image has alt or is hidden |
| 1.3.1 | Info & relationships | Headings, lists, sections are real HTML elements |
| 1.4.3 | Contrast (minimum) | 4.5:1 text, 3:1 large text |
| 1.4.10 | Reflow | No horizontal scroll at 320px |
| 2.1.1 | Keyboard | Everything reachable with Tab, operable with Enter/Space |
| 2.4.1 | Bypass blocks | Skip link |
| 2.4.6 | Headings & labels | Describe topic or purpose |
| 2.4.7 | Focus visible | Visible focus ring |
| 2.5.8 | Target size | ≥ 24×24 px |
| 4.1.2 | Name, role, value | Buttons/links have accessible names |
